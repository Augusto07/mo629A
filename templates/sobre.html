O que é o projeto

Este projeto conta quantas pessoas entraram na sala de aula do Instituto de Computação da Unicamp. A contagem é feita por um ESP32, um microcontrolador com Wi-Fi, e os resultados aparecem em gráficos neste site.

É um projeto de mestrado em desenvolvimento, e o painel mostra os dados à medida que o ESP32 os envia.

Como funciona

  1. O ESP32 detecta quando uma pessoa entra na sala.
  2. A cada entrada, ele envia o registro pela internet para o servidor deste site.
  3. O servidor guarda o registro com data e hora em um banco de dados.
  4. O painel lê os registros guardados e desenha os gráficos.

O que o painel mostra

  • Entradas hoje: o total de pessoas que entraram na sala no dia atual.
  • Entradas por dia: o total de cada dia, nos últimos 7, 14 ou 30 dias.
  • Entradas por hora: como as entradas se distribuem ao longo de um dia que você escolhe.
  • Sinal Wi-Fi: a força do sinal que o ESP32 recebe ao longo do dia, para acompanhar a qualidade da conexão.

Todos os horários seguem o horário de Brasília.

Tecnologias

  • ESP32 para a coleta dos dados
  • Python e Flask para o servidor
  • SQLite para o banco de dados
  • Chart.js para os gráficos
  • PythonAnywhere para a hospedagem
