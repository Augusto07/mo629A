O que é o projeto

Este projeto conta quantas pessoas entraram na sala de aula do Instituto de Computação da Unicamp. A contagem é feita por um ESP32, um microcontrolador com Wi-Fi, e os resultados aparecem neste painel.

É um projeto de mestrado em desenvolvimento, e o painel mostra os dados à medida que o ESP32 os envia.

Como funciona

  1. O ESP32 detecta quando uma pessoa entra na sala.
  2. Ele envia os registros pela internet para a nuvem (AWS), onde ficam guardados em um banco de dados.
  3. Este painel consulta esses dados e os mostra na tela.

O que o painel mostra

  • Há pessoas na sala? Sim ou Não, de acordo com os dados mais recentes.
  • Pessoas na sala ao longo do dia: um gráfico com a quantidade de pessoas em cada momento do dia escolhido.

Tecnologias

  • ESP32 para a coleta dos dados
  • AWS para a API e o banco de dados
  • Python e Flask para servir o painel
  • Chart.js para o gráfico
  • PythonAnywhere para hospedar o painel
