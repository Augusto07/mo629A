O que é o projeto

Este projeto, desenvolvido no Instituto de Computação da Universidade Estadual de Campinas (UNICAMP), utiliza tecnologias de Internet das Coisas (IoT) e informações do sinal Wi-Fi para monitorar a presença de pessoas em uma sala de aula.

A coleta de dados é realizada por um ESP32, que obtém informações de CSI (Channel State Information) do sinal Wi-Fi e as envia para um servidor. Essas informações são utilizadas pelo sistema para acompanhar a presença no ambiente e disponibilizadas neste painel para visualização.

Como funciona

  1. O ESP32 realiza medições de CSI (Channel State Information), obtendo informações relacionadas ao sinal Wi-Fi no ambiente.
  2. As medições coletadas são enviadas pela internet para a infraestrutura da AWS, onde são disponibilizadas por meio de uma API e armazenadas em um banco de dados.
  3. O painel consulta a API para obter os dados e apresentar as informações de presença.
  4. Os dados são organizados e exibidos em indicadores e gráficos, permitindo acompanhar os registros de presença ao longo dos dias e horários.

O que o painel mostra

  • Presença atual: indica se há pessoas na sala, considerando a leitura mais recente recebida.
  • Registros hoje: apresenta a quantidade de registros de presença exibidos no gráfico no dia atual.
  • Maior atividade: identifica o horário com maior quantidade de registros de presença no dia.
  • Total no período: apresenta o total de registros com presença no intervalo selecionado.
  • Presença por dia e horário: gráfico em que cada ponto verde representa um registro de presença em determinado horário e dia.

Tecnologias

  • ESP32: microcontrolador utilizado para realizar as medições de CSI do sinal Wi-Fi.
  • AWS: infraestrutura em nuvem utilizada para disponibilização da API e armazenamento dos dados.
  • Python e Flask: utilizados no desenvolvimento do servidor e do painel web.
  • Chart.js: biblioteca utilizada para a construção dos gráficos.
  • PythonAnywhere: plataforma de hospedagem do painel web.
